# MartShop – E-Commerce Web Application

MartShop is a full-stack e-commerce web application that I independently designed and developed as a practical project in web development.

The project was built using Laravel, PHP, MySQL, HTML, CSS, and JavaScript. It includes the main functions of an online store, from product browsing to order management.

## Main Features

- User registration and login
- Product browsing by categories and brands
- Search and filtering
- Product details pages
- Shopping cart management
- Address and phone information
- Delivery options
- Order confirmation and order history
- Discounts and special offers
- Product variants
- Administrative dashboard
- Product and category management
- Customer order management
- Responsive Arabic RTL interface
- Interactive user interface components

## Technologies Used

- Laravel

- HTML5

- JavaScript
